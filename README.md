# Sanfe · Equipo Alevín

Aplicación estática para el equipo Alevín de Sanfe.

## Publicación e instalación

GitHub Pages sirve `index.html` con HTTPS. En iPhone, abre la URL publicada desde Safari y usa **Compartir → Añadir a pantalla de inicio**. En Android, también puedes descargar `Sanfe-movil.zip` y abrir `Sanfe-android.html` con Chrome.

## Datos y acceso

Las fotos, asistencias y eventos se guardan en el almacenamiento local del navegador y no se sincronizan entre dispositivos. El código del modo entrenador está en JavaScript del cliente, así que no protege datos confidenciales ni debe considerarse autenticación segura.
